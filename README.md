# «Привилегия» — демо главной страницы

Апартаменты посуточно в ЖК «Привилегия» (Казань, Горки, ул. Братьев Касимовых, 35).
Концепция «21 час»: страница проживает одни сутки в квартире, с 15:00 до 12:00.

## Запуск

```bash
node tools/serve.mjs 8480
```

Потом откройте http://localhost:8480/. Подойдёт любой статический сервер (`npx serve`, `python -m http.server`).
Без сервера (по file://) страница откроется, но камин не оживёт: браузер не даёт читать пиксели фото.

## Где что менять

Все данные лежат в `assets/js/config.js`: контакты, цены (`showPrices`), форматы, отзывы, удобства, сцены «21 часа», подписи к фото галереи.

## Откуда фото

- **Клиент:** гостиная с камином (hero), гостиная с диваном, кухня-гостиная, вертикальный кадр кухни, верх кадра спальни с лесом.
- **Видео клиента:** 10 кадров (ванна, дверь, прихожая, стол с сервизом, лобби, фен, полотенца, книги, завтрак, ванная с LED-зеркалом). Поля и водяные знаки InShot и Avito обрезаны. Тизер `assets/video/teaser.mp4` (7 с, без звука).
- **Яндекс.Карты:** холлы ЖК, фасад, двор, вход, велопарковка, спальни, ванная, гостиная. Всё скачано локально.
- **VK:** закрыт капчей и логин-стеной, оттуда ничего не взято.
- **Карта района:** статичная схема из тайлов OpenStreetMap (`tools/build-map.mjs`). Интерактивная Яндекс-карта загружается по кнопке.

## Инструменты самопроверки (`tools/`)

- `audit.mjs` — проверка интерактивов
- `tour.mjs` — скриншоты по секциям
- `overflow.mjs` — поиск горизонтального скролла
- `fire-frames.mjs` — кадры камина крупным планом
- `build-assets.mjs` — сборка фото
